# Auri – Updates

Hier liegen nur die Update-Dateien für die Desktop-App **Auri** von Andorfer Webdesign, kein Quellcode.

Installierte Auri-Apps fragen unter `https://andorfer-webdesign.de/auri/updates/` nach neuen Versionen. Die Adresse leitet auf das neueste Release dieses Projekts weiter.

Jedes Release enthält:

- `latest.yml`: Versionsnummer und Prüfsumme
- `Auri-Setup-<Version>.exe`: Windows-Installer
- `Auri-Setup-<Version>.exe.blockmap`: damit Updates nur die geänderten Teile laden
